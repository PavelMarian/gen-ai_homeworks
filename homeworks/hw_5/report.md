## Валидатор схемы

```
VALID_TOOLS = {"get_fx_rate", "get_key_rate", "get_inflation", "calculate"}

def validate_plan(plan: Plan) -> list[str]:
    errors = []
    for sq in plan.subquestions:
        for tool in sq.expected_tools:
            if tool not in VALID_TOOLS:
                errors.append(f"Подвопрос {sq.id}: недопустимый инструмент '{tool}'")
    return errors
```

**Проблема:** Валидатор не ловит невалидные планы, так как агенты применяются корректные инструменты. Выполнение упирается в лимит итерацийю

Затем вычислить накопленный рост как отношение конечного ИПЦ к начальному, вычесть 1 и перевести в проценты. Для этого потребуются два вызова get_inflation и один calculate.

## Вывод

По результатам прогонов можно заключить, что паттерн PWC оправдан в узком классе задач -- для большинства реальных вопросов одиночный агент остаётся более надёжным и быстрым решением. В представленной таблице одиночный агент является абсолютным лидером: PWC (14/30) и PWC+валидатор (16/30) уступают одиночному агенту (26/30), проваливаясь на задачах с нечёткой семантикой (Q2, Q6) и вычислительно сложных (Q3). 

Теоретически, PWC целесообразен только для структурированных числовых запросов, где важна параллельность и предотвращение арифметических ошибок. Однако в рамках текущего эксперимента для большинства реальных вопросов одиночный агент остаётся более надёжным и быстрым решением.
